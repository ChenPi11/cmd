# 论把 `cmd` 移植于类 Unix 之道

&emsp;&emsp;夫令行天下者，莫若微软之`cmd`；志在四方者，孰逾Unix之诸邦？今欲脱其壳而植异壤，舍Win32之旧藩，就POSIX之新域，此非独技痒之戏，实乃通变之机、补天之巧也。盖东西二土，文法判若河汉，一尚大小之浑然，一崇路径之斜正；一赖注册之渊薮，一恃文本之简素。今以彼之短，效此之长，犹使楚客操吴音，越裳服周冕，其难可知，而其趣亦无穷焉。

&emsp;&emsp;原夫`cmd`之行于Windows，全仗NT内核之势，挟图形之威，历二十余载，号令亿兆之众。然其名既广，其用亦彰，奈何困守一隅，不与BSD、Linux通呼吸？
今有奇士ChenPi11，慨其不可用，遂仗三尺之码，重构其神，不假MFC之繁，不慕.NET之华，独倚C89之古法，赖libc之常道，历数载之功，
使游于Haiku、OpenBSD、PureDarwin乃至System V之间，截图昭然，若列国舆图，盖欲以微躯，填鸿沟之壑，破壁垒之坚也。

&emsp;&emsp;夫天下之事，相克相生，亦相济相成。Windows与Unix，一主闭源而广布，一崇开放而分驰，语法异趣，精神殊途。然则圣人云“君子和而不同”，移殖之要，不在同其貌，而在通其神，不在袭其迹，而在会其意。譬如刻舟求剑，徒执旧痕；郑人买履，宁信尺度，皆失其本。此作不贪微软之API，不慕图形之华彩，惟以POSIX为基，以终端为画，使旧日批令，得行于新壤；使陈年脚本，复振于异乡。观其志，不在攻城略地，而在使旧雨新知，得一认祖归宗之所耳。

&emsp;&emsp;然则其术虽奇，其道亦密。空言无益，请陈其概。且夫外壳之妙，首在能传令，次在能执批，又次在能通人。此三者，此作兼得之矣。今试分而论之：

&emsp;&emsp;其一曰**批处理之机杼**，旧规犹存。`CALL`、`GOTO`若循环之锁钥，开阖有序，使流程曲折而不断；`SHIFT`移位而参数流转，%0至%9，递相承接，
若江河之奔涌；`SETLOCAL`与`ENDLOCAL`，划域而治，不染外境，犹郡县之封疆；标签跳转，以冒号导之，虽千行万行，终不失其纲。  

&emsp;&emsp;其一曰**环境变量之承袭**，毫厘不爽。大小写浑然而不分，`%VAR%`得展，任命名之纷纭；`%CD%`映现时之径，`%DATE%`示当日之辰，
`%TIME%`报刻漏之数，`%ERRORLEVEL%`昭成败之迹；更兼`/v:on`延迟之妙，使动态展开，若庖丁解牛，游刃于句式之间。  
（双股骈偶，起首论批处理逻辑与环境变量语义）

&emsp;&emsp;其一曰**内建之令，四十有余**，足以应万变。`DIR`查其目，可列长名、隐文、时戳，兼施通配之符；
`COPY`移其文，能合多简、辨覆盖、效验证，不失原旨；`ECHO`发声如故，可启闭回显，可显示字符串；`TYPE`显字犹新，虽二进制亦强行吐之；`DEL`、
`REN`、`MD`、`RD`，莫非旧识；`ASSOC`、`FTYPE`，犹存扩展关联之制；`START`启新程，`TITLE`易标帜，`COLOR`改颜貌，
俨然Windows旧观未改。  

&emsp;&emsp;其一曰**管道重导，毫厘不爽**，三流各得其所。竖线`|`传stdout以通stdin，使前后相衔，
若吐纳之相续；尖角`<`从文件取给，`>`覆写旧物，`>>`添附新章，此三者悉遵微软优先级之律；更有`2>`分定误处，使错者归其所，不混于常流；一行之内，
可叠数重，如网之有目，目有纲，虽繁不乱。  

&emsp;&emsp;其一曰**语言之化，随俗而安**，见人文之趣。置`LANG`为zh_CN则华章立现，存`zh_MS`则戏谑横生，
更辟`zh_WY`以文言传意，兼蓄四体，可谓风雅备至；此非徒供嬉戏，实乃示人以“可译”之能，使五洲之士，各以其语得窥旧令之妙，其包容之怀，可比诸子百家和鸣。  

&emsp;&emsp;其一曰**构建之简，本固枝荣**，显匠人之心。携`make`则GNU下速就，执`tbuild.sh`则SysV中
亦易，无外部依赖，不假`fnmatch`、`settimeofday`之属，悉以`lsysport.c`自覆之；其码纯依C89，避指定初始、避C99类型，虽老旧
之编译器，亦能驯顺；且行于Haiku之雅，OpenBSD之谨，PureDarwin之志，甚至System V之古，有图所载，历历可征，兼容可谓有海纳百川之广矣。

&emsp;&emsp;总而言之，此重演之物，效其形而遗其躯，移其用而守其魂。彼自嘲“不能反克Windows”，实乃明哲之辞，示不侵其原域；又严守GPLv3之约，开诚布公，招天下共修，岂仅为奇技淫巧耶？且观其文档，备述贡献之道，设AutoRun之初始，置历史记忆之档案，虽微末之节，亦体贴入微。然八股之体，贵在代圣贤立言，僵若槁木，动辄桎梏；而此`cmd`之移，代机器立命，反成活趣。东西异趣，而能曲尽其妙，吾观其行迹，虽曰补天之戏，实亦足见今日开源之风，浩浩汤汤，不囿于疆域，不限于门庭，凡有志者，皆可执耒耜而耕天下，此其所以为可贵也。
