MSG_HELP_CMD
"启动命令解释程序的新实例。\n"
"\n"
"CMD [/C|/K] [/S] [/Q] [/D] [/A|/U] [/T:{<b><f>|<f>}]\n"
"    [/E:{ON|OFF}] [/F:{ON|OFF}] [/V:{ON|OFF}] [string]\n"
"\n"
"  /C  执行 string 指定的命令，然后退出。\n"
"  /K  执行 string 指定的命令并保持运行。\n"
"  /S  修改 /C 或 /K 之后 string 的处理方式。\n"
"  /Q  关闭回显。\n"
"  /D  禁用 AutoRun 命令的执行。\n"
"  /A  输出格式: ANSI。\n"
"  /U  输出格式: Unicode (不完全支持)。\n"
"  /T:{<b><f>|<f>}  设置前景/背景颜色。\n"
"  /E:ON   启用命令扩展 (默认)。\n"
"  /E:OFF  禁用命令扩展。\n"
"  /F:ON   启用文件和目录名称补全。\n"
"  /F:OFF  禁用文件和目录名称补全 (默认)。\n"
"  /V:ON   启用延迟环境变量扩展。\n"
"  /V:OFF  禁用延迟环境变量扩展 (默认)。\n"
"\n"
